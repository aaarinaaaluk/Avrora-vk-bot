# AVRORA — VK-бот для предварительной проверки медицинских утверждений

Проект принимает сообщения через VK Callback API, ищет материалы в ограниченном каталоге медицинских источников и просит GigaChat осторожно оценить найденные фрагменты. Без подходящих фрагментов или без доступной модели бот не объявляет утверждение истинным или ложным.

## Что подключено

- **GigaChat API**: получение OAuth Access Token через `/api/v2/oauth`, кэширование токена в памяти процесса и запросы к `/v1/chat/completions`. Access Token запрашивается повторно до истечения срока действия.
- **PubMed**: поиск публикаций и аннотаций через официальный NCBI E-utilities API; полный текст статьи может быть недоступен.
- **Google Fact Check Tools API**: дополнительный поиск уже опубликованных проверок. Этот коннектор включается, если задан `GOOGLE_FACT_CHECK_API_KEY`.
- **Локальные PDF**: поиск фрагментов в `data/documents/`. Сейчас в архиве есть локальный документ по витамину D/рахиту.
- **Каталог разрешённых источников**: `data/sources.json`. В нём перечислены источники из требований; `automated_search: true` обозначает реализованный путь поиска, а `false` — запись в каталоге без автоматического коннектора в текущей версии. Запись в каталоге сама по себе не означает, что её материалы уже загружаются в проверку.

Модель получает фактические фрагменты с заголовками и ссылками, а не просто список доменов. Она должна оценивать только переданные сведения. Ответ без достаточных доказательств возвращается как `INSUFFICIENT`. Результат является предварительным информационным анализом и не заменяет медицинского специалиста.

## Установка и запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните значения. Файл `.env` исключён из Git, не добавляйте его в публичный репозиторий и не отправляйте API-ключи в сообщения или логи.

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Проверка состояния: `GET /`.
Проверка утверждения через REST API: `POST /verify` с JSON-телом `{"claim":"Витамин C предотвращает простуду"}`.
Классификация запроса без поиска доказательств: `POST /analyze` с таким же телом.

## Где вставлять API-ключи

### 1. GigaChat — основной ключ ИИ

1. Откройте свой проект GigaChat API в GigaChat Studio.
2. Перейдите в **Настройки API → Получить ключ**.
3. Сохраните `Authorization Key`, `Client ID` и `Client Secret`; секретные значения показываются только при выдаче.
4. Вставьте значение `Authorization Key` в строку `GIGACHAT_AUTH_KEY=` файла `.env`.

Пример формата (это не настоящий ключ):

```dotenv
GIGACHAT_AUTH_KEY=ваш_реальный_Authorization_Key
```

Кавычки не нужны. Не вставляйте в эту строку Access Token из ответа OAuth: проект сам получает и обновляет краткоживущий Access Token. Если вместо готового Authorization Key у вас только `Client ID` и `Client Secret`, оставьте `GIGACHAT_AUTH_KEY` пустым и заполните `GIGACHAT_CLIENT_ID` и `GIGACHAT_CLIENT_SECRET`.

### 2. Google Fact Check Tools API — необязательный ключ

Создайте API key в Google Cloud Console, включите Fact Check Tools API и вставьте ключ в `GOOGLE_FACT_CHECK_API_KEY=`. Без него бот всё ещё выполняет поиск в PubMed и локальных PDF.

### 3. VK Callback API

Заполните `VK_GROUP_TOKEN`, `VK_CONFIRMATION_CODE` и `VK_SECRET` в `.env` значениями из настроек сообщества VK. Укажите адрес `https://<ваш-домен>/vk/callback` в Callback API сообщества и выберите событие нового сообщения. Для локального тестирования понадобится доступный извне HTTPS-туннель или сервер.

### 4. PubMed / NCBI — необязательные параметры

Публичный поиск работает и без ключа. Если есть NCBI API key, задайте `NCBI_API_KEY`; можно также указать контактный email в `NCBI_EMAIL` для идентификации клиента.

## Текущие границы интеграции

Каталог включает ВОЗ, AHRQ, EFSA, CINAHL, Cochrane Library, UpToDate, DynaMed, PubMed/MEDLINE, источники Минздрава России, RusMed, КиберЛенинку, eLibrary, Медвестник, НЭБ и другие указанные в требованиях ресурсы. Но автоматические адаптеры прямо сейчас реализованы только для PubMed, Google Fact Check Tools (при наличии ключа) и PDF-файлов из `data/documents/`. Для остальных записей каталог задаёт разрешённую область источников и назначение, но не запускает автоматический поиск на их сайтах. Подписные ресурсы нельзя считать доступными без соответствующей подписки.

Проверка не должна считаться медицинской рекомендацией. Для личных симптомов, диагноза, лекарств, дозировок, беременности, детей и неотложных ситуаций обратитесь к квалифицированному специалисту или местной службе помощи.
